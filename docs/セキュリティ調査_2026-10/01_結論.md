# 結論

調査日: 2026-10-26  
対象: このリポジトリの `package-lock.json` とソース。本番の Cloudflare ゾーンや、実際に配信されているビルドは見ていない。

預かり金システムは **Next.js 14.2.16**（React 18.3.1）で、ログイン判定は `middleware.ts` に集約されている。API ハンドラ自身は、空床の公開 API を除き、セッションを見ていない。

この組み合わせは、2025年3月に公開され、その後も対策漏れのサイトへの攻撃が続いた **ミドルウェア認証回避（CVE-2025-29927）** の条件に当てはまる。14 系でこの問題が十分に塞がれた版は **14.2.26**。いまの 14.2.16 はそれより前である。

ニュースで「サーバが乗っ取られた」と報じられた **React2Shell（CVE-2025-55182 / Next.js 側 CVE-2025-66478）** は、安定版の Next.js 14 には当たらない。2026年10月14日の **`use cache` 経由の遠隔コード実行（GHSA-673q-mjm6-r5xr）** も Next.js 16.0.0〜16.4.0 が対象で、このリポジトリには当たらない。

当たるものと当たらないものを分けると、次のとおり。

| 区分 | 内容 |
| --- | --- |
| 今の版で当たる | ミドルウェア認証回避（CVE-2025-29927）。ログインを迂回できる。入出金 API はハンドラ側でもログインを見ていない |
| 今の版で当たる | 2025年12月の Server Components サービス停止（CVE-2025-55184）。14 系の修正は 14.2.35。データの持ち出しではない |
| 当たらない | React2Shell の遠隔コード実行。安定版 14 系と React 18 は対象外 |
| 当たらない | 2026年10月の `use cache` 遠隔コード実行。Next.js 16 のみ |
| 当たらない | 2026年5月の新しいミドルウェア回避（segment-prefetch、動的ルートパラメータ）。15.2 以降 / 15.4 以降 |
| 14 系に修正がない | 2026年5月の Server Components サービス停止（CVE-2026-23870）。ベンダーの影響範囲は Next.js 13 と 14 の全版。修正は 15.5.16 以降と 16.2.5 以降だけ。このリポジトリに `"use server"` はない |

Next.js 14 はサポート終了で、14 系の最後のリリースは 2025-12-12 の **14.2.35** である。2026年5月以降の修正は 14 系に降りていない。14.2.35 へ上げても、2026年5月分は残る。
