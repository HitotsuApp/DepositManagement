# 実施した修正

実施日: 2026-10-26。本番へのデプロイはまだしていない。OpenNext への置き換えはしていない。

## Next.js

`package.json` の `next` を 14.2.16 から **14.2.35** に固定した。14 系の最終版で、認証回避（CVE-2025-29927）と 2025年12月のサービス停止（CVE-2025-55184）の修正が入っている。

`npm run pages:build`（`@cloudflare/next-on-pages` 1.13.16）は、Next.js 14.2.35 を検出して完了した。

## 業務 API のログイン確認

`lib/requireApiSession.ts` を追加した。ログイン済みの印が無ければ JSON の 401 を返す。ログイン画面や Google へは転送しない。

業務 API の 35 ハンドラの先頭でこれを呼ぶ。空床の公開 API（`/api/public/vacancy`）とログイン API（`/api/auth`）は対象外のまま。

## 確認

ローカルの Next.js 14.2.35 で確認した。

- 印が無い `/api/facilities` は 401。ログイン画面への転送は無い
- 印がある `/api/facilities` は 200。ログイン画面への転送は無い
- 印が無い画面を開くと、今までどおりログイン画面が1回開く
- 空床の公開 API は、API キーが無いとき 503 のまま

ログイン済みの確認は、ローカル用の印を作って API に付けた。Google の画面で実際にログインする操作はしていない。
